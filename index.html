A decision benchmark for selecting cryo-EM re-refinements

Selecting the candidate with the highest map correlation increased packed-side-chain χ1 disagreement with higher-resolution structures in 119 of 131 sequence groups.

Main findings

In a prespecified cohort of single-particle entries at 3.0–3.6 Å, each deposited model was re-refined with four protocols, and a rule chose one of five actions, including keeping the deposited model. The choice was scored against a separately determined, higher-resolution structure of the same protein.

How the benchmark works

“We treat re-refinement as a decision in which the deposited model remains a scored no-operation action alongside the refined candidates. A stated rule, such as taking the candidate with the highest same-map correlation, selects one action in each case, and the selected model is scored against a separately determined, higher-resolution structure of the same protein.”

From the introduction

  1. 01 · Case

    A deposited model and its map

    Keeping the model unchanged is the no-operation action.

  2. 02 · Candidates

    Five actions per case

    No operationPhenix ×1Phenix ×2ServalcatCryoNet.Refine
  3. 03 · Rule

    A stated rule picks one

    For example, the highest support-matched same-map CCmask; ties favour no operation.

  4. 04 · Score

    Score against a higher-resolution structure

    χ1 disagreement over packed side chains, those with at least 18 Cα atoms within 10 Å.

Selection loss
How much the rule changes disagreement compared with keeping the deposited model. Positive values are worse.loss = d(selected action) − d(no operation)
Observed regret
How far the chosen action is from the best action that was on offer.regret = d(selected action) − min d(offered actions)

d is chemical-symmetry-aware χ1 disagreement with the comparison structure, in degrees. Cases sharing a comparison structure or a 95% sequence-identity group are averaged first, and those clusters are weighted equally; intervals are 95% bootstrap intervals over clusters.

Results across cohorts

The highest-correlation rule lost agreement in MEDIC, in an independent replication selected from archive metadata, in the 3.0–3.6 Å cohort and in low/high-resolution pairs from the same study. Selecting with a half map that was withheld from re-refinement reduced the loss but did not remove it.

Servalcat was chosen most often

The rule chose Servalcat in 147 of 167 entries. With every Servalcat configuration removed, it still lost 2.32° in MEDIC and 2.14° in the earlier replication.

Disagreement increased with map weight

Within Servalcat in MEDIC, disagreement rose by 1.55°, 3.15° and 5.15° at half, automatic and double map weight, as CCmask gains rose from 0.040 to 0.053 to 0.068.

CryoNet.Refine was rarely selected

CryoNet.Refine reduced disagreement in the earlier replication (−0.39°) but was selected in only 6 of 156 entries, because other candidates gained more in map fit.

Using Primum

Primum fixes the cohorts, references, residue supports and scoring, so new methods can be compared with no operation and with the published reference results.

Evaluate a new refiner

Run it on the supplied starting coordinates and score its output on the fixed reference correspondence and residue support.

Evaluate a new selection rule

Make one action choice per case from the available model and map features, then score the choices against the outcome table. Existing candidates can be reused without running refinement again.

Compute the decision summaries

Primum (Python, NumPy only) computes selection loss, observed regret, leave-one-action-out sets, single-action acceptance rules, risk–coverage and the cluster bootstrap from a long table with these columns:

caseclusteractionselection scoreoutcome

Five reporting items for re-refinement benchmarks

  1. The no-operation endpoint value.
  2. The candidate set and selection rule, with selection loss and observed regret.
  3. Coordinate agreement against a separately determined comparison, alongside map fit and geometry.
  4. Refinement coverage and the loss among accepted cases.
  5. The independent statistical units and scored residue support.
